# 3D-атлас человека

Открытый бесплатный русскоязычный сайт об анатомии человека. Каждый раздел — живая 3D-модель с анимацией и понятный текст: что это, что делает, из чего состоит, интересные факты.

Для взрослых, которые показывают ребёнку, как устроено тело, для педагогов и подростков.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты + проверка на эмодзи
npm run build      # сборка в dist/
```

## Правила проекта

- Ни одного эмодзи — только иконки. `npm run check:emoji` падает при находке.
- 3D-модели — только собственные, процедурные (строятся в коде).
- Тексты — в `src/content/ru/`, строки интерфейса — в `src/i18n/`.

## Раздел «Глаз»

Процедурная модель правого глаза в миллиметрах (`src/models/eye/`): 28 частей, у каждой своя геометрия и материал.

- `anatomy.ts` — профили тел вращения: стенка, слои сетчатки, ресничное тело, хрусталик, радужка (чистая математика, покрыта тестами).
- `geometry.ts`, `build.ts` — поверхности вращения, срезы, трубки (нерв, мышцы), сосуды сетчатки, радужка с меняющимся зрачком.
- `textures.ts` — текстуры, нарисованные в canvas: радужка, склера, конъюнктива, хориоидея, сетчатка.
- `EyePart.tsx` — общее поведение части: разнос, подсветка, призрачный режим, скрытие, плоскость разреза.
- Рассмотреть детали: выбор части (камера подлетает, остальные становятся призрачными), слои с «глазками», разрез сбоку, «дно глаза», разнос на части (`src/three/StageExplorer.tsx`).
