# 3D-атлас человека

Открытый бесплатный русскоязычный сайт об анатомии человека. Каждый раздел — живая 3D-модель с анимацией и понятный текст: что это, что делает, из чего состоит, интересные факты.

Для взрослых, которые показывают ребёнку, как устроено тело, для педагогов и подростков.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты + проверка на эмодзи
npm run build      # сборка в dist/
```

## Правила проекта

- Ни одного эмодзи — только иконки. `npm run check:emoji` падает при находке.
- 3D-модели — только собственные, процедурные (строятся в коде).
- Тексты — в `src/content/ru/`, строки интерфейса — в `src/i18n/`.

## Раздел «Глаз»

Процедурная модель правого глаза в миллиметрах (`src/models/eye/`): 28 частей, у каждой своя геометрия и материал.

- `anatomy.ts` — профили тел вращения: стенка, слои сетчатки, ресничное тело, хрусталик, радужка (чистая математика, покрыта тестами).
- `geometry.ts`, `build.ts` — поверхности вращения, срезы, трубки (нерв, мышцы), сосуды сетчатки, радужка с меняющимся зрачком.
- `textures.ts` — текстуры, нарисованные в canvas: радужка, склера, конъюнктива, хориоидея, сетчатка.
- `EyePart.tsx` — общее поведение части: разнос, подсветка, призрачный режим, скрытие, плоскость разреза.
- Рассмотреть детали: выбор части (камера подлетает, остальные становятся призрачными), слои с «глазками», разрез сбоку, «дно глаза», разнос на части (`src/three/StageExplorer.tsx`).

## Раздел «Зуб»

Процедурная модель на неявных полях (SDF) в `src/models/teeth/`, сетки строятся в фоновых потоках (Surface Nets + сглаживание Таубина).

- `anatomy.ts` — 16 постоянных зубов (верх и низ, от резца до зуба мудрости): профиль коронки, бугры и борозды, ЭЦГ, корни с изгибом и бороздами, каналы, толщина эмали и цемента.
- `build.ts` — ткани зуба как замкнутые тела (эмаль, дентин, пульпа, цемент, каналы): на разрезе видны настоящие срезы.
- `jaw.ts` — нижний первый моляр в кости: десна, периодонт, корковая и губчатая кость, нижнечелюстной канал.
- `arch.ts` — зубной ряд: 32 зуба на дугах с десной и сосочками.
- Режимы сцены: витрина четырёх типов, «Зуб в челюсти», «Зубной ряд»; разрез, разнос, слои.

## Раздел «Кишечник»

Процедурная многокомпонентная модель в `src/models/intestine/`: 50 частей в 9 группах (тонкая кишка, отделы толстой, признаки толстой, прямая кишка и сфинктеры, слои стенки, содержимое, брыжейка и сосуды, срез под микроскопом, соседние органы).

- `anatomy.ts` — центральные линии кишки (толстая от дна слепой до ануса, тонкая от привратника до илеоцекального клапана, отросток), радиусы, гаустры и тении, круговые складки, толщина слоёв.
- `geometry.ts`, `build.ts` — поверхности вокруг линий: у каждого отдела пять вложенных поверхностей (наружная, граница круговой мышцы, подслизистой, слизистой), тении-ленты, полулунные складки, сальниковые отростки, сфинктеры, лобково-прямокишечная мышца, брыжейка с аркадами, артерии и вены, лимфоузлы, нервы, соседи.
- `materials.ts` — материалы стенки: изнанка поверхности красится цветом среза слоя, поэтому на любом разрезе в кольце стенки видны настоящие слои без отдельных «крышек». Перистальтика тонкой кишки — сжатие радиуса вокруг оси в вершинном шейдере.
- `IntestinePart.tsx` — поведение части: разнос по отделам и слоям, подсветка, призрачный режим, скрытие, свои плоскости разреза для таза.
- `WallScene.tsx` — срез стенки тонкой кишки под микроскопом: слои, круговая складка, ворсинки, крипты, пейерова бляшка, нервные сплетения и увеличенная ворсинка с капиллярами и млечным синусом. Включается кнопкой «Стенка под микроскопом» или выбором любой «микро»-части.
- Виды: целый, фронтальный разрез, срез сверху; разнос на части; выбранная часть отдельно; подлёт камеры к каждой части.

## Раздел «Желчный пузырь»

Процедурная многокомпонентная модель в `src/models/gallbladder/`: 34 части в 6 группах (отделы пузыря, слои стенки, содержимое, желчные протоки, сосуды-нервы-лимфа, соседние органы).

- `anatomy.ts` — центральная линия пузыря, профиль радиуса (дно, тело, воронка с карманом Хартмана, шейка), рамки вдоль линии, слои стенки, «соты» слизистой, печень с ямкой пузыря и воротами, пути протоков, сосудов и нервов, плоскости разрезов, цикл сокращения (чистая математика, покрыта тестами).
- `geometry.ts`, `build.ts` — оболочки вокруг линии пузыря (поверхность, серозная оболочка, подсерозная основа, мышечный слой с пучками, собственная пластинка, слизистая и складки-соты со смещением вершин, синусы Рокитанского — Ашоффа), винтовая складка Хейстера, протоки с желчью внутри, ампула, сфинктер Одди, большой сосочек, артерии и вены с ветвлением по стенке, нервы с узелками, лимфоузлы, печень, ложе пузыря, связка, треугольник Кало, двенадцатиперстная кишка со складками, поджелудочная железа.
- `materials.ts` — материалы слоёв: изнанка поверхности красится цветом среза слоя, поэтому на любом разрезе в кольце стенки видны настоящие слои без отдельных «крышек».
- `textures.ts` — бесшовные canvas-текстуры: стенка с сосудистой сетью, мышечные пучки, слизистая, печень, железа.
- `GallbladderPart.tsx`, `GallbladderModel.tsx` — поведение части (разнос слоями от центра пузыря, подсветка, призрачный режим, скрытие, плоскости разрезов только для пузыря), камера к частям, потоки желчи и крови, сокращение пузыря после «жирной еды» (желчь выдавливается по пузырному протоку в кишку).
- Виды: целый, фронтальный разрез вдоль оси, срез поперёк тела пузыря; разнос на слои и части; выбранная часть отдельно.
