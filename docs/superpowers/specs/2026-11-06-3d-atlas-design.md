## 1. Что это и зачем

Открытый бесплатный русскоязычный сайт об анатомии человека. Каждый раздел — это живая 3D-модель с анимацией, которую можно крутить и нажимать, а рядом точный и понятный текст: что это, что делает, из чего состоит, интересные факты.

Почему: в России почти нет открытых веб-3D-атласов на русском (зарубежные аналоги — BioDigital Human, Zygote Body). Идея родилась из желания показать ребёнку, как устроено тело, включая тему «откуда я взялась».

### Для кого [Хозяин]

- взрослые, которые наглядно показывают ребёнку строение тела;
- педагоги;
- малыши (тодлеры) — под присмотром взрослого;
- подростки — читают сами.

Детей не недооцениваем: ребёнок в 4 года способен понять и запомнить базовое строение тела и настоящие названия органов [Хозяин].

### Тон текста [Хозяин]

- Язык простой, но без сюсюканья. Настоящие термины («альвеолы», «поджелудочная железа») — с пояснением.
- Формулировки и манера — как в референсах: яркий короткий подзаголовок («Красный курьер кислорода»), дальше по делу, с цифрами.
- Основной текст адресован взрослому и подростку; блок «Как рассказать ребёнку» — точные короткие фразы, которые взрослый может прочитать вслух как есть [моё решение по форме блока].

## 2. Цели, не-цели, анти-цели

### Цели

1. Все 23 раздела (список в §5) опубликованы, в каждом — своя 3D-модель с анимацией, интересные факты, подробно «что делает» и «из чего состоит» [Хозяин].
2. Переключатель 18+ на сайте [Хозяин]. По умолчанию сайт безопасен для ребёнка; 18+ открывает подробную анатомию половых органов и откровенные иллюстрации [Хозяин].
3. На каждой странице аннотация: «Сайт носит информационный характер. Заметили ошибку? Напишите нам» [Хозяин].
4. Нигде нет эмодзи — только иконки [Хозяин, жёстко].
5. Сайт задеплоен на Coolify, когда всё готово [Хозяин].
6. Всё записано в TigerWiki проекта [Хозяин].

### Не-цели (в этой версии)

- Аккаунты, комментарии, CMS/админка, оплата.
- Другие языки, кроме русского — в первой версии. Но **переводы запланированы** [Хозяин 06.11.2026]: русский, английский, китайский, узбекский, казахский, «индийский» (предположительно хинди — уточнить), немецкий. Поэтому все тексты интерфейса и контента хранятся отдельно от кода и с самого начала устроены так, чтобы добавить язык без переписывания компонентов.
- Медицинская диагностика, советы по лечению.
- Тесты/викторины, режим урока с заданиями (кандидаты в Роадмап).

### Анти-цели (провал, даже если формально работает)

- Хоть один эмодзи в интерфейсе, тексте или данных.
- Дизайн, похожий на референсы или на типовой «тёмный шаблон с неоновыми градиентами».
- 3D-модели, в которых нельзя узнать орган («шарик с подписью»).
- Сюсюкающий тон или, наоборот, текст, понятный только медику.
- 18+ материал виден или загружается при выключенном переключателе.
- Ошибки в фактах (особенно цифры).
- Сайт тормозит на обычном телефоне или долго грузится.

## 3. Ограничения

- **3D-модели делаю сам, процедурно в коде** [Хозяин]. Чужие модели не берём: ни код моделей из референсов, ни Z-Anatomy, ни BodyParts3D, ни скачанные GLB.
- **Дизайн сайта проектирую сам с нуля** [Хозяин]. Из референсов дизайн и компоненты не берём.
- **Из референсов берём только содержание** [Хозяин]: списки клеток, белков и прочего, интересные факты, манеру формулировок. Каждый факт сверяется; сомнительные выкидываются (пример: «эритроцит душит анаэробные инфекции» — неверно).
- Референсы: `референсы разные/*.zip` (три архива: fable51, хайку, muse) — данные в `src/data/*.ts`.
- Хостинг: Coolify на VPS-1 (правила деплоя — инструкция Хозяина TIGER_AGENT_UNIVERSAL, деплой только с подтверждения Хозяина).
- Аудитория в России: не зависеть от сервисов, которые там работают плохо (Google Fonts, внешние CDN) — всё своё, отдаём с нашего сервера.

## 4. Устройство сайта

### 4.1 Страницы

| URL | Что |
|---|---|
| `/` | Главная: 3D-фигура человека + все разделы по системам организма |
| `/razdel/<slug>` | Страница раздела (23 шт., slug латиницей: `serdce`, `pechen`…) |
| `/kletki/<slug>` | Карточка клетки или белка внутри раздела «Клетки и белки» |
| `/o-proekte` | О проекте, источники, лицензия, как сообщить об ошибке |
| `404` | Страница «не найдено» с поиском |

У каждой страницы свой `<title>`, описание и картинка для соцсетей. HTML страниц должен отдаваться готовым (пререндер при сборке), чтобы поисковики видели текст [моё решение; способ — на выбор строителя].

### 4.2 Главная

1. **Первый экран** — полупрозрачная 3D-фигура человека, внутри светятся органы. Наводишь/нажимаешь на орган — подпись; второй клик ведёт в раздел. Фигура медленно «дышит», сердце бьётся.
2. **Поиск** по разделам и частям органов («альвеолы» → «Лёгкие»).
3. **Разделы, сгруппированные по системам** — у каждой системы свой цвет (§6.2):
   - Клетка и молекулы: Клетки и белки
   - Опора и движение: Скелет, Мышцы
   - Обзор: Внутренние органы
   - Нервная система и чувства: Мозг, Глаз, Ухо
   - Дыхание: Лёгкие
   - Кровообращение: Сердце, Кровеносная система
   - Пищеварение: Зуб, Желудок, Печень, Поджелудочная железа, Желчный пузырь, Кишечник
   - Мочевыделение: Почки, Мочевой пузырь
   - Кожа и её производные: Волос и ногти
   - Размножение и развитие: Женская репродуктивная система, Мужская репродуктивная система, Беременность
   - Регуляция: Гормоны
4. Короткий блок «Как пользоваться атласом со ребёнком» (3 шага) и подвал.

### 4.3 Страница раздела (на примере «Сердце»)

1. **3D-сцена** на первом экране: модель сама анимирована, крутится пальцем/мышью, приближается. Нажатие на часть — подсветка, подпись, текст части прокручивается в видимую зону.
   Кнопки сцены: Пауза анимации · Разрез (где есть) · Подписи вкл/выкл · Сбросить вид · **Показ** (на весь экран, тёмная сцена, без лишнего — для класса или ребёнка).
2. **Шапка**: название, латинское название, яркий подзаголовок.
3. **Цифры карточками**: размер, вес, сколько работает, рекорды.
4. **Что делает** — 2–3 абзаца.
5. **Из чего состоит** — список частей с пояснениями; связан с моделью (наведение/нажатие подсвечивает часть в 3D и наоборот).
6. **Как рассказать ребёнку** — 1–2 точные фразы.
7. **Интересные факты** — 3–5 карточек.
8. **Чем болеет и как беречь** — коротко, без запугивания, без советов по лечению («обратитесь к врачу») [моё решение].
9. **Связанные разделы**.
10. **Подвал** с аннотацией (§4.6).

### 4.4 Раздел «Клетки и белки»

- Вводная модель «Как устроена клетка»: мембрана, ядро, митохондрии, ЭПС, комплекс Гольджи, рибосомы, лизосомы — с подписями.
- Каталог с фильтрами: Кровь · Иммунитет · Мозг · Ткани · Половые клетки · Белки.
- Состав каталога — объединение списков трёх референсов без дублей, примерно 25 клеток и 9–10 белков:
  - кровь: эритроцит, тромбоцит;
  - иммунитет: нейтрофил, эозинофил, базофил, моноцит, макрофаг, Т-лимфоцит (в т.ч. Т-киллер CD8+), B-лимфоцит, NK-клетка, дендритная клетка;
  - мозг: нейрон (пирамидный), астроцит, олигодендроцит, микроглия;
  - ткани: фибробласт, миоцит (мышечное волокно), гепатоцит, стволовая клетка (гемопоэтическая);
  - половые клетки и развитие: сперматозоид, яйцеклетка, зигота;
  - белки: гемоглобин, антитело IgG, коллаген, кератин, актин, миозин, инсулин, тубулин (микротрубочка), амилаза.
- Карточка клетки: модель с анимацией (нейтрофил ползёт и выпускает отростки, антитело хватает антиген, миозин «шагает» по актину, гемоглобин связывает кислород), размер, срок жизни, количество в теле, что делает, из чего состоит (с долями, где уместно), с чем борется, факты.
- Половые клетки и зигота доступны без 18+ — это биология, нужна для темы «откуда я взялась» [моё решение; в референсах они были под 18+ — см. открытые вопросы].

### 4.5 Переключатель 18+

- В шапке на всех страницах: переключатель «18+», по умолчанию выключен.
- Включение → окно подтверждения «Мне есть 18 лет» / «Отмена» (с иконкой, без эмодзи). Выбор запоминается в браузере; выключить можно в один клик.
- При выключенном 18+ откровенный материал **не загружается вовсе** (отдельные чанки кода/данных), а не просто размыт.
- Что меняется при включении: в разделах «Женская/Мужская репродуктивная система» — подробная модель включая наружные половые органы и полные подписи, физиология; в «Беременности» — подробности зачатия и родов. При выключенном: внутренние органы схематично и детально-безопасно (матка, яичники, трубы, овуляция; яички, протоки, образование сперматозоидов), развитие плода по неделям.
- 18+-блоки помечены маленьким значком «18+».

### 4.6 Аннотация и обратная связь

- В подвале каждой страницы: «Сайт носит информационный характер. Заметили ошибку? Напишите нам», где «Напишите нам» — ссылка на канал связи (см. открытые вопросы).

### 4.7 Доступность и удобство

- Работает одинаково на телефоне, планшете и большом экране; на телефоне сцена сверху, текст ниже [Хозяин доверил мне].
- Жесты рассчитаны на ребёнка: нельзя «потерять» модель (ограничен зум, нет панорамы, кнопка сброса всегда видна).
- `prefers-reduced-motion` → анимации на паузе по умолчанию.
- Управление с клавиатуры, у каждой модели текстовое описание для скринридеров.
- Нет WebGL → вместо сцены аккуратная заглушка и весь текст остаётся.

## 6. Визуальный дизайн [Хозяин доверил; стиль выбран Хозяином 06.11.2026]

### 6.1 Направление: «Музей науки» [Хозяин выбрал из трёх вариантов превью]

Превью: `docs/mockups/preview-v1.html`, вариант 1. Светлый, чистый, современный: много воздуха, крупный плотный гротеск в заголовках, белые карточки, модель стоит как экспонат на светлом подиуме под мягким студийным светом.

Отвергнуто Хозяином: «Хогвартс» и «1890» (бумажная фактура, книжная антиква) — никакой винтажности. Отзыв на превью: «немножечко нейрослопно» → в чистовой версии убрать шаблонные приёмы: моноширинные надписи капслоком над каждым блоком, одинаковые сетки карточек, точки-маркеры повсюду, тире-подзаголовки. Выразительность — через композицию, масштаб и саму 3D-модель, а не через декор.

Тёмная тема — по системной настройке + переключатель (основа — вариант 3 «Тёмная витрина» из превью). Режим «Показ» — всегда тёмный, как «Тёмная витрина».

### 6.2 Цвет

- Фон `#F7F7F4`, карточки `#FFFFFF`, текст `#121212`, вторичный текст `#5F6166`, линии `#E1E1DC`.
- Тёмная тема: фон `#101114`, карточки `#17191E`, текст `#F0EEE9`, вторичный `#A3A6AD`, линии `#2A2D33`.

- Подписи — HTML-плашки с тонкой линией-выноской к точке на модели.
- Выделение части — подсветка контуром и лёгкое «выдвижение» части.

## 7. Как это сделано (техника)

- **Стек** [моё решение; совпадает с референсами, поэтому знаком Хозяину]: Vite + React + TypeScript, three.js через @react-three/fiber и drei, Tailwind CSS, React Router, иконки lucide-react.
- **Контент** — типизированные файлы данных (TypeScript), по файлу на раздел. Тексты отделены от кода моделей.
- **Модели** — по модулю на раздел/клетку, грузятся лениво, только когда открыт раздел. Рендер приостанавливается, когда сцена не на экране; качество (разрешение) снижается на слабых устройствах.
- **Производительность**: главная должна открываться быстро на обычном телефоне; 3D-код каждого раздела — отдельный кусок, не грузится заранее.
- **Сборка** — статические файлы с пререндером страниц.
- **Деплой**: Dockerfile (сборка на Node → раздача через nginx, корректные 404, кэширование статики) → Coolify на VPS-1, **отдельный Project** «3D-атлас человека», источник — GitHub `main`, автодеплой по пушу. Деплой — только после подтверждения Хозяина в формате его инструкции. После — smoke-test и запись в вики (Релизы, Прогресс, Инфраструктура).
- **TigerWiki**: после утверждения этого документа — заполнить ТЗ, Контекст, Решения, TODO, Роадмап, Инфраструктуру, API для ИИ, Саммари, Прогресс. Секреты в вики — только названия.
